# Sample photo credits

Every image in this folder ships on a commercial site, so each one needs a
source and a licence recorded here before it goes in. Own photographs are the
simplest answer — no attribution to track, no licence to re-check later.

If a licence requires attribution, it has to be visible to visitors somewhere,
not only in this file.

`src/utils/samples.js`. The sample row stays hidden until that last step.
